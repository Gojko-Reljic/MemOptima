## Release boundary

Version 0.4.0 is a Linux-only, local, on-demand, read-only evidence collection release. It retains
bounded repeated snapshots of supported rootful Docker cgroup v2 memory data and the current
point-in-time assessment in an owner-only JSON Lines artifact. It requires cgroup v2, the memory
controller, and host memory PSI. It does not contact the Docker socket or Docker API, invoke the
Docker CLI from the executable, change cgroup or host settings, create a daemon, database, or
hidden history, infer a trend, predict an OOM event, diagnose a leak, or apply an action.

The complete product boundary is defined in [0.4.0 Scope](../0.4.0-scope.md), and the persisted
schema is defined in [Evidence Artifact Format](../evidence-artifact-format.md).
