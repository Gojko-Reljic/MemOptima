## Release boundary

Version 0.3.0 is a Linux-only, local, on-demand, read-only assessment release. It supports the
documented rootful Docker `systemd` and `cgroupfs` cgroup v2 layouts, requires cgroup v2, the memory
controller, and host memory PSI, and does not use the Docker socket or Docker API.

It assesses one current cgroup snapshot using documented `memory.high`, finite `memory.max`, and
`memory.events` boundary and OOM signals. It does not support rootless Docker, cgroup v1,
Kubernetes discovery, continuous collection, retained history, trend analysis, forecasting,
automatic recommendations, or cgroup and host-memory modifications. The complete boundary is
defined in [0.3.0 Scope](../0.3.0-scope.md).
