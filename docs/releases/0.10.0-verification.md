## Release Boundary

0.10.0 evaluates the shared memory-current forecast using bounded rolling origins at fixed
operational horizons. It provides accuracy evidence against a paired persistence baseline while
keeping collection, analysis, and output read-only. It also makes evidence and manifest JSON
parsing strict for duplicate object names and nesting depth.

The release does not predict OOM events, confirm memory leaks, diagnose anomalies, recommend a
configuration change, or perform any automatic action. Evidence and trend-manifest schema versions
remain 1. The complete contract is defined in [0.10.0 Scope](../0.10.0-scope.md).
