## Release boundary

0.5.0 adds local, read-only inspection of version-1 MemOptima evidence artifacts. It securely opens
only explicit regular non-symlink files, reads JSON Lines incrementally, validates record lifecycle,
and reports a human-readable session and container summary. A missing terminal record is shown as
incomplete while its valid preceding evidence remains readable.

The release does not contact Docker or the network during inspection, infer trends, predict OOM,
diagnose leaks, certify workload health, recommend changes, or apply actions. The full contract is
defined in [0.5.0 Scope](../0.5.0-scope.md).
