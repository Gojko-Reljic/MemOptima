## Release Boundary

0.9.1 extends the terminal trust boundary to artifact-facing output and diagnostics. It renders
untrusted terminal-control text safely, rejects malformed evidence scalars before they reach
readers, and preserves raw valid values for filesystem handling and analysis. The evidence schema
remains version 1.

### Known Issues in Earlier Releases

Version 0.9.0 escapes ASCII controls only in the `CGROUP PATH` cells of `trends analyze` and
`forecast evaluate`. `inspect evidence`, `forecast evidence`, and artifact, manifest, path, or
filesystem diagnostics are not equivalently protected in that earlier release.

0.9.1 adds no forecasting, trend, assessment, intelligence, recommendation, or automatic-action
behavior. It does not normalize identity values, introduce a public trusted-text type, or define
the duplicate-JSON-key policy; that parser-boundary work is planned for v0.10. The complete
contract is defined in [0.9.1 Scope](../0.9.1-scope.md).
