## Docker cgroup v2 integration verification

The explicitly invoked integration target was executed on a suitable rootful Docker, cgroup v2
host:

```bash
cmake --build --preset release --target memoptima_docker_integration
```

The target pulled or used the configured `alpine:3.24.4` image, started one uniquely named and
labeled temporary container, and verified all of the following:

- `memoptima containers` discovered the full ID of that real Docker container;
- `memoptima container <FULL_ID>` returned its detailed cgroup memory report;
- the target removed only the container it created, by its exact ID.

After the target completed, the following read-only cleanup check returned no containers:

```bash
docker ps -a --filter label=com.memoptima.integration=true --format '{{.ID}} {{.Names}}'
```

## Release boundary

Version 0.2.0 is a Linux-only, local, read-only Docker-aware cgroup v2 observability release. It
supports the documented rootful Docker `systemd` and `cgroupfs` layouts, requires cgroup v2,
the memory controller, and host memory PSI, and does not use the Docker socket or Docker API.

It does not support rootless Docker, cgroup v1, Kubernetes discovery, continuous collection,
persistence, risk forecasting, recommendations, or cgroup and host-memory modifications. The
complete boundary is defined in [0.2.0 Scope](../0.2.0-scope.md).
