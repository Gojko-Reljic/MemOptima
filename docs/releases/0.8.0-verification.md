## Release Boundary

0.8.0 adds a local, read-only measurement of the existing linear `memory.current` projection. The
`memoptima forecast evaluate <MANIFEST>` command validates explicitly selected schema-version-1
artifacts and compares the first eligible forecast history with its immediately following holdout
observation. It reports coverage, mean absolute error, signed bias, and explicit unavailable or
excluded statuses.

The command does not predict OOM events, diagnose memory leaks or anomalies, certify workload
health, recommend a memory limit, or modify a host, container, or cgroup. Its full contract is
defined in [0.8.0 Scope](../0.8.0-scope.md),
[Forecast Evaluation Report Format](../forecast-evaluation-report-format.md), and
[Trend Manifest Format](../trend-manifest-format.md).
