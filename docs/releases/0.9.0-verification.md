## Release Boundary

0.9.0 hardens display of artifact-derived cgroup paths in the two CLI reports that render them and
documents that public evidence-stream callbacks are provisional until traversal succeeds. It adds no
monitoring, prediction, intelligence, or automatic-action capability. The evidence schema remains
version 1, and the original cgroup-path value remains intact for validation and analysis.

The release does not reject an artifact merely because its cgroup path contains a control byte,
normalize identity values, alter unrelated CLI tables, predict OOM, diagnose a memory leak or
anomaly, recommend a configuration change, or modify a host, container, or cgroup. Its full
contract is defined in [0.9.0 Scope](../0.9.0-scope.md).
