## Release boundary

0.7.0 adds local, read-only cross-session analysis of Docker container `memory.current` evidence.
The `memoptima trends analyze <MANIFEST>` command validates explicitly selected schema-version-1
artifacts and reports a separate trend for each compatible container observation epoch. It does not
scan directories or contact remote services.

This release does not predict OOM events, diagnose memory leaks, certify workload health, apply
automatic recommendations, or modify hosts, containers, or cgroups. The full contract is defined in
[0.7.0 Scope](../0.7.0-scope.md), [Trend Manifest Format](../trend-manifest-format.md), and
[Trend Report Format](../trend-report-format.md).
