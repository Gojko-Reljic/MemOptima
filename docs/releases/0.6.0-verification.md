## Release boundary

0.6.0 adds local, read-only, evidence-based forecasting of a finite cgroup `memory.max` crossing.
The forecast requires a continuous container series, at least three observations across at least ten
seconds, available `memory.current`, and a stable finite `memory.max`. It never modifies the host,
containers, cgroup settings, or the input artifact.

This release does not predict OOM events, diagnose memory leaks, certify workload health, or apply
automatic actions. The full contract is defined in [0.6.0 Scope](../0.6.0-scope.md).
